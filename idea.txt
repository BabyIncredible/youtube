You are a senior Python architect and automation engineer. Build a complete, production-oriented Python project that automatically creates a faceless YouTube video and optionally uploads it to YouTube.

Do not create one enormous Python file. Use a clean, modular architecture with separate components for topic selection, script generation, voice generation, visual generation, video rendering, thumbnail creation, quality validation and YouTube uploading.

Before writing code:

1. Inspect the current workspace.
2. Present a short implementation plan.
3. List the files you will create.
4. Identify external dependencies and system dependencies.
5. Then implement the project phase by phase.
6. After every phase, run the relevant tests and fix errors before continuing.
7. Do not leave important functions as pseudocode, TODOs or empty placeholders unless an external credential is genuinely required.
8. If API credentials are unavailable, create functional mock providers so the pipeline can still be tested locally.

# Primary objective

The project must execute this workflow:

1. Select an unused topic from a CSV file.
2. Ask an LLM API to generate:

   * Video title
   * Video description
   * Narration
   * Scene-by-scene visual plan
   * On-screen text
   * Image-generation prompts
   * Tags
   * Thumbnail text and image prompt
3. Validate the generated structured response.
4. Generate an AI voice-over for every scene.
5. Generate an image for every scene.
6. Measure the actual duration of each narration file.
7. Create one video clip per scene using the generated image and narration.
8. Add subtle pan-and-zoom animation to still images.
9. Add readable on-screen text.
10. Generate subtitles.
11. Combine all scene clips into one 1920×1080 MP4 video.
12. Optionally add quiet background music.
13. Generate a 1280×720 thumbnail.
14. Perform automated audio, video and metadata quality checks.
15. Upload the video and thumbnail to YouTube as private by default.
16. Save all intermediate files, logs and pipeline state.
17. Mark the topic as completed only after the pipeline succeeds.
18. Support resuming a failed run without regenerating successful assets.

Python coordinates the pipeline. FFmpeg performs the actual audio and video rendering.

Do not hard-code a specific AI model name throughout the code. Model names must be configurable through environment variables or config.yaml.
